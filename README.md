# Neo Babylon 開放創作素材包

《新巴比倫》開放創作計畫官方素材包：收錄官方已公開的人物與場景視覺參考圖、中英日譯名對照，歡迎創作者用於非商業視聽創作。

完整規範以官方頁面為準：https://neobabylon.icareu.tw/open-creation/

## 使用規範摘要

### 你可以
- 使用本素材包的人物、場景圖片，進行 AI 圖像、影片或聲音等**非商業**創作。
- 改變表現手法：畫風、鏡頭、剪輯、配音、音樂與聲音設計。
- 保留角色核心設定、角色關係、事件脈絡與事件結果，做不同媒材的視覺化或聲音化呈現。
- 公開發表作品時，清楚標示為《新巴比倫》**非官方衍生創作**，並註明原作與創作者署名。
- 將作品提交給官方，爭取網站收錄、社群推薦與後續合作機會。

### 你不可以
- 新增角色、新地點、新支線／主線，或自行補完未公開的世界觀（暫不開放文字類延伸創作）。
- 改變角色核心設定、人物關係、故事事件結果，或將官方劇情改寫成互相矛盾的版本。
- 冒充官方正史、正式續作，或以出版社／作者名義發布。
- 商業使用：販售、募資、發行 NFT、商業授權，皆須事先取得官方書面同意。
- 散布原作全文、完整章節、付費內容或尚未公開的劇情設定。
- 將作品用於政治、仇恨、色情，或明顯損害原作形象的宣傳。

※ 創作者保有自己作品的權利，但不取得《新巴比倫》原始人物、故事、設定與品牌所有權；未經正式採納的作品不構成正史。

## 內容說明

| 路徑 | 說明 |
|---|---|
| `characters.md` | 角色列表（含中／英／日譯名、出處、描述、參考圖連結） |
| `scenes.md` | 場景列表（同上） |
| `index.html` | 網頁瀏覽器：搜尋、分類瀏覽、放大檢視、下載（可用瀏覽器直接開啟，或部署至 GitHub Pages） |
| `data/characters.json`、`data/scenes.json` | 機器可讀的角色／場景資料（含 repo 內圖片相對路徑） |
| `assets/characters/<角色ID>/` | 各角色視覺參考圖 |
| `assets/scenes/<場景ID>/` | 各場景視覺參考圖 |

譯名欄位留空者表示官方尚未公布，請勿自行翻譯使用。
